# Arquivos necessários ao projeto

Esta lista ajuda a equipe a reunir os materiais originais. Não substitui os arquivos fornecidos pelo professor.

## Materiais que precisam ser adicionados ou conferidos

| Arquivo/material | Para que serve | Ação da equipe |
|---|---|---|
| PDF do trabalho | Contém os requisitos e orientações oficiais | Adicionar uma cópia, se a divulgação for permitida, ou registrar onde a equipe o consulta |
| Código-base do professor (`main.c`, se fornecido) | Estrutura inicial e declarações exigidas | Comparar com o arquivo-base deste repositório e preservar as declarações originais |
| `E1_Impressora01.dll` x64 | Biblioteca de comunicação com a impressora | Conferir a versão e a licença antes de compartilhar; se não puder publicar, documentar como obtê-la |
| XML SAT de teste | Entrada para o teste de impressão SAT | Adicionar somente o XML de exemplo autorizado pelo professor |
| XML de cancelamento SAT | Entrada para o teste de cancelamento | Adicionar somente o XML de exemplo autorizado pelo professor |
| Documentação/exemplos da DLL | Explicam funções, parâmetros e retornos | Guardar os materiais autorizados e conferir as assinaturas antes de programar |

## Cuidados com arquivos fiscais e pessoais

- Não publique XML fiscal real que contenha CNPJ, CPF, endereço, chave de acesso ou dados de clientes.
- Prefira arquivos de demonstração fornecidos pelo professor.
- Não publique a DLL até confirmar que a licença permite redistribuição.
- Não substitua os arquivos oficiais por XML inventado.
- O nome exato do XML de cancelamento e os caminhos usados pelo programa devem ser conferidos no PDF e no código do professor.

## Organização

Conforme a orientação registrada para este trabalho, confira no PDF se a DLL e os XMLs devem ficar na pasta raiz do projeto. Não mova esses arquivos para outra pasta sem confirmar que o código e o professor permitem.
